# Coralyst Support

Coralyst is a macOS application for monitoring coral reef sites through hydrophone data.

## Get help

To report a problem or request help, [open a GitHub issue](https://github.com/Gleenryan/CH5_Biorocks/issues/new).

Please include:

- Your macOS version.
- The Coralyst version or build you are using.
- A short description of what you expected and what happened.
- Reproduction steps and relevant screenshots, when appropriate.

GitHub issues are public. Do not post microphone recordings, precise private locations, hardware identifiers, credentials, or other sensitive information.

## Microphone troubleshooting

If Coralyst cannot access an input device:

1. Open **System Settings > Privacy & Security > Microphone**.
2. Confirm that Coralyst has microphone permission.
3. Reconnect the input device and use the refresh control in Coralyst.
4. Confirm that another application is not exclusively controlling the device.

## Privacy and local data

Read the [Coralyst Privacy Policy](https://github.com/Gleenryan/CH5_Biorocks/blob/main/PRIVACY.md) for details about local storage, microphone processing, and data handling.

Coralyst does not provide a developer-hosted user account or cloud database. Site, hydrophone, detection, and coral-health records are stored locally on your Mac. If you need help removing local app data, open a support issue without including sensitive data.
